# TESO MELODIES Android app

This repository is being prepared to build an Android APK for https://tesomelodies.com.

## Source project required

Upload the supplied project archive to the repository root with this exact filename:

`TESO-MELODIES-main.zip`

Then open **Actions → Build TESO MELODIES APK → Run workflow**. The workflow extracts the project, configures a Capacitor Android wrapper, builds a debug APK, and uploads it as a downloadable workflow artifact.

## Live website updates

The Android wrapper is configured to open https://tesomelodies.com directly. This means songs, artist uploads, and website content published to the live site are loaded from the website and do not require a new APK. Changes to the native Android shell, app icon, or permissions require a new APK build.

## Important

The APK generated by this workflow is a debug APK for testing and direct installation. A Google Play release requires a separately signed release build and Play Console setup.
